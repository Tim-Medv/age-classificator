# Классификатор возраста по тексту

## Описание

Данный проект представляет собой автоматизированный сбор данных из социальной сети «ВКонтакте» и создание модели машинного обучения для определения возрастной группы пользователя по тексту комментариев. Для удобства пользователей реализовано оконное приложение на Tkinter, позволяющее вводить текст и получать предсказание возрастной группы в реальном времени.

## Структура проекта

- **parsing_vk_script.py** – скрипт для  многопоточного сбора комментариев из заданных групп ВКонтакте с использованием VK API. Собранные данные сохраняются в файл `dataset/data.csv`.
- **code_final_diplom.ipynb** – Jupyter Notebook с предобработкой и обучением моделей.
- **main.py** – оконное приложение для ввода текста и предсказания возрастной группы пользователя на основе обученной модели.
- **unit_tests.py** – набор unit-тестов для проверки корректности функций предобработки текста и работы пользовательского интерфейса.



## Конфигурация

Перед запуском скрипта сбора данных укажите свои VK API токены в списке `TOKENS` в файле `parsing_vk_script.py`. При необходимости измените перечень групп в `GROUP_URLS`.

## Использование

### 1. Сбор данных
```bash
python parse dataset/parsing_vk_script.py
```
По умолчанию данные сохраняются в `parse dataset/dataset/data.csv`.

### 2. Анализ и обучение модели

Откройте `ML script/code_final_diplom.ipynb` в Jupyter Notebook и выполните все ячейки для обработки данных, обучения и оценки модели.

### 3. Запуск приложения
```bash
python windowed application/main.py
```
Откроется окно приложения, в котором можно ввести текст и получить предсказание возрастной группы.

### 4. Тестирование
```bash
python -m unittest windowed application/unit_tests.py
```
